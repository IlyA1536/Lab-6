# Lab-6
# Застосування numpy

## Мета роботи
Отримати поглиблені навички роботи з numpy; дослідити поняття лінійної регресії та градієнтного спуску.

---

## Структура проєкту

- `lab6.py` — основний скрипт із реалізацією:
  - Генерація даних навколо заданої прямої
  - Метод найменших квадратів (ручна реалізація)
  - `numpy.polyfit` (для порівняння)
  - Градієнтний спуск
  - Візуалізація результатів

---

## Використані бібліотеки

- `numpy` — для чисельних обчислень
- `matplotlib` — для побудови графіків

---

## Основні етапи

1. **Генерація даних**
   - Випадкові точки з шумом навколо прямої `y = kx + b`

2. **Метод найменших квадратів**
   - Ручна реалізація через середні значення
   - Порівняння з результатами `np.polyfit`

3. **Градієнтний спуск**
   - Ітеративне оновлення коефіцієнтів
   - Побудова графіка збіжності (MSE)

4. **Графіки**
   - Показ усіх трьох прямих (істинна, МНК, градієнтна)
   - Графік похибки для градієнтного спуску
